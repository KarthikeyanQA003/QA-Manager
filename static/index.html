Set up Google sign-in

One-time setup. Create a Google OAuth Client ID, then paste it below.

  1. Open Google Cloud Console → Credentials (sign in with your company account; create a project if asked).
  2. If prompted, configure the OAuth consent screen: User type Internal, app name “Test Case Manager”.
  3. Create credentials → OAuth client ID → Application type Web application.
  4. Under Authorized JavaScript origins add http://localhost:8765 — no redirect URI needed.
  5. Create, then copy the Client ID (ends with .apps.googleusercontent.com).
